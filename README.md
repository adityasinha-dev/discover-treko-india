# 🌍 Treko — Smart Travel Planning

Treko is a **MERN-based travel planning platform** focused on providing a centralized solution for discovering destinations, accommodation, and travel options across India.

## 🚀 Features

- 🇮🇳 Explore destinations across India
- 🏨 Discover accommodation options
- 🚗 Explore travel options
- 📋 Plan and organize trips
- 🏢 Business registration for travel services
- 📱 Responsive and modern UI

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Deployment:** Vercel
